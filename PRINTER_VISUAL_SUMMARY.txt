┌──────────────────────────────────────────────────────────────────────────────┐
│                          FLOW OVERVIEW                                       │
└──────────────────────────────────────────────────────────────────────────────┘

  ORDER CREATION FLOW
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. Staff creates order in POS                              │
  │ 2. Backend validates and saves order                       │
  │ 3. Backend fetches restaurant printer config               │
  │ 4. Printer service generates KoT content                   │
  │ 5. TCP connection to kitchen printer                       │
  │ 6. KoT printed with restaurant branding                    │
  │ 7. Order response returned to client                       │
  └─────────────────────────────────────────────────────────────┘

  PAYMENT FLOW
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. Payment marked as "paid"                                │
  │ 2. Backend updates order status                            │
  │ 3. Backend fetches restaurant printer config               │
  │ 4. Printer service generates Bill content                  │
  │ 5. TCP connection to counter printer                       │
  │ 6. Bill printed with restaurant branding                   │
  │ 7. Payment response returned to client                     │
  └─────────────────────────────────────────────────────────────┘

  TABLE STATUS FLOW
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. Kitchen marks order as "served"                         │
  │ 2. Backend updates table status to "occupied"              │
  │ 3. Table shows customer is eating                          │
  │                                                             │
  │ 4. Payment settled                                         │
  │ 5. Backend updates order status to "completed"             │
  │ 6. Backend updates table status to "available"             │
  │ 7. Table becomes available for next customer               │
  └─────────────────────────────────────────────────────────────┘
